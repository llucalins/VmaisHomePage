# Vmais Comunicação - Site da Agência

Site institucional da Vmais Comunicação.

## Tecnologias

- React 18
- Vite
- Styled Components
- Framer Motion
- Lenis

## Requisitos

- Node.js 18+
- npm

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

```text
src/
  components/
  App.js
  main.jsx
  index.css
index.html
vite.config.js
```
